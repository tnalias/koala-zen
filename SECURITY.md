# Security policy

Koala Zen has no server: everything runs in your browser, and the optional Infomaniak features talk only to Infomaniak, with your own tokens.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub: **Security** tab, then **Report a vulnerability**, or https://github.com/tnalias/koala-zen/security/advisories/new

Include the browser and Koala Zen version, the steps to reproduce, and what an attacker could do. You will get an answer as soon as possible, and a fix is released before any details are made public.

## Supported versions

Only the latest version receives security fixes.
